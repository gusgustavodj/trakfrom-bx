# Support

This pre-alpha has bounded compatibility. Windows is
`OFFICIAL_MAINTAINER_VALIDATED`; physical musical evidence covers Traktor Pro 4.
macOS is `EXPERIMENTAL` with community ports welcome; Linux is `NOT_SUPPORTED`
and not currently targeted. A future `COMMUNITY_VALIDATED` platform records
contributor evidence, separately from maintainer physical validation.

For non-sensitive bugs, use the bug report template with OS, host/Python/package
versions, source format, reproduction, playback/removal state and sanitized logs.
Do not upload real libraries, audio, credentials or personal data. See SECURITY.md
for sensitive reports. Feature requests and platform proposals have separate
templates; there is no guaranteed response time or compatibility commitment.

Windows CI tests software contracts and packaging. Core CI is a portability
signal only. Neither CI nor a contributor's report means the maintainer physically
tested macOS, USB hardware, real hotplug/mounting/permissions or Traktor playback.
Track Collection cleanup is not implemented; preserve the source USB during use.
